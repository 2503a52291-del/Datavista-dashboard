# DataVista – AI Tools Usage Analytics

DataVista is an interactive dashboard that analyzes which AI tools students use, their purposes, usage frequency, productivity, and overall experience.

## Features

* AI tool usage analysis
* Student purpose and preferences
* Usage frequency and time-spent analysis
* Productivity and learning insights
* Interactive charts and visualizations

## Technologies Used

* HTML
* CSS
* JavaScript
* CSV Dataset

## Dataset

Survey data collected from 500 student responses about AI tool usage and experiences.

## Deployment

Hosted using GitHub Pages.
